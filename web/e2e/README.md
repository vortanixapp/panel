# Сквозные тесты интерфейса

Тесты запускают настоящую production-сборку панели в Chromium. API подменяется в браузере (`support/mock-api.ts`): вызовы пишутся в `api.calls`, а запрос без ответа в моке считается ошибкой теста.

```bash
npm run build
npx playwright install chromium
npm run e2e
```

Локально можно взять установленный Chrome: `E2E_CHANNEL=chrome npm run e2e`. Один файл: `npx playwright test e2e/billing.spec.ts`.

Что покрыто: вход, дашборд (карточки, питание, живые данные потоком), страница сервера и её вкладки, вкладка логов (поток консоли и запасной опрос), пополнение через тестовый шлюз, аренда сервера.

Мок отвечает так, как нам кажется правильным: он не проверяет настоящий API. Если меняете форму ответа API, обновите `support/mock-api.ts`.
