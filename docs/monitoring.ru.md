# Мониторинг

[English](monitoring.md) · [Русский](monitoring.ru.md)

Необязательные Prometheus и Grafana рядом с панелью. Они показывают, как ведут
себя API, база данных и relay под нагрузкой, чтобы медленные места искать по
цифрам, а не наугад. Без вашей команды ничего не запускается.

## Запуск

```bash
docker compose -f deploy/docker-compose.yml -f deploy/docker-compose.images.yml --profile monitoring up -d
```

Grafana слушает порт `3001` машины (`GRAFANA_PORT`), поэтому домен не нужен.
Откройте `https://<IP машины>:3001`. Сертификат создаётся при первом запуске и
самоподписанный, поэтому браузер один раз предупредит: продолжайте, соединение
всё равно зашифровано. Если есть файрвол, откройте порт 3001.

Вход `admin`, пароль — `GRAFANA_ADMIN_PASSWORD` из `deploy/.env` (его создаёт
`scripts/init-env.sh`). Если значение пустое, создаётся случайный пароль,
показать его можно так:

```bash
docker compose -f deploy/docker-compose.yml exec grafana cat /certs/admin-password
```

Grafana применяет пароль только при самом первом запуске, потом его меняют на
странице профиля Grafana. Дашборд **Vortanix: обзор** ставится сам.

Prometheus не публикуется совсем и доступен только внутри сети Docker: у него нет
своего входа по паролю. Любой запрос к нему можно выполнить в Grafana: **Explore**,
источник Prometheus. Метрики хранятся 15 дней, срок меняется переменной
`PROMETHEUS_RETENTION`.

Те же ключевые графики есть и в самой панели: **Администрирование →
Производительность**. Там не нужен ни дополнительный порт, ни пароль, и работает
это одинаково на домене и на IP.

## Что показывает дашборд

- Запросы к API в секунду и время ответа p95 по маршрутам, ошибки 5xx.
- База данных: время запросов p95 для пулов записи и чтения, медленные запросы,
  занятые соединения пула и время ожидания свободного соединения.
- Горутины и память API.
- Запросы и время ответа relay (трафик агентов).

## Как читать

- Маршрут с высоким p95 и большим числом запросов в секунду оптимизируют первым.
- Если «Соединения пула базы» упираются в лимит и растёт «Ожидание соединения из
  пула», пул мал или часть запросов слишком долго держит соединение.
- Медленные запросы здесь только считаются, текст запроса пишется в лог API как
  `slow query ... sql=...`. Порог задаёт `DB_SLOW_QUERY_MS` (по умолчанию 500 мс).

## Профилирование

Чтобы снять профиль CPU или памяти API, добавьте в `deploy/.env` строку
`PPROF_ADDR=127.0.0.1:6060` и пересоздайте сервис `api`. Адрес находится внутри
контейнера и через Caddy не публикуется. Профиль снимается в контейнере, а
разбирать его можно где угодно:

```bash
docker compose -f deploy/docker-compose.yml exec api wget -qO /tmp/cpu.pprof "http://127.0.0.1:6060/debug/pprof/profile?seconds=30"
docker compose -f deploy/docker-compose.yml cp api:/tmp/cpu.pprof .
go tool pprof cpu.pprof
```
