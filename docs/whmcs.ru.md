# Интеграция с WHMCS

[English](whmcs.md) · [Русский](whmcs.ru.md)

Панель подключается к WHMCS как модуль подготовки услуг. WHMCS принимает заказы
и оплату, панель создаёт и обслуживает игровые серверы.

## Возможности

| Событие в WHMCS | Действие в панели |
|---|---|
| Создание услуги | Создаётся сервер по тарифу панели. Для клиента заводится учётная запись или используется существующая с тем же email |
| Приостановка | Сервер останавливается и блокируется, клиент получает уведомление со ссылкой на услугу в WHMCS |
| Возобновление | Снимается блокировка, наложенная WHMCS. Блокировку, выставленную администратором панели, WHMCS не снимает |
| Удаление | Сервер удаляется с ноды вместе с файлами |
| Смена продукта или опций | Меняются тариф и ресурсы сервера. Новые лимиты применяются при следующем запуске |
| Смена пароля | Меняется пароль учётной записи клиента в панели |
| Продление | Обновляется дата следующего платежа |
| Изменение данных клиента | В панели обновляются email и имя |
| Вход в панель | Клиент попадает на страницу сервера без ввода пароля |
| Обновление статистики | В WHMCS записывается занятое место на диске |

В личном кабинете WHMCS клиент видит статус, адрес, игру, локацию и ресурсы
сервера, может запустить, перезапустить и остановить его. Администратор WHMCS
видит те же данные на странице услуги, может переустановить сервер и
синхронизировать адрес и дату платежа.

Сервер, созданный через WHMCS, не продлевается с баланса панели: сроком
аренды управляет WHMCS. На вкладке тарифа такого сервера показаны номер
услуги, дата следующего платежа и ссылка на услугу в WHMCS. Продление, смену
тарифа и удаление сервера клиент выполняет в WHMCS.

## Подключение

1. В панели откройте «Интеграции», раздел WHMCS, и нажмите «Скачать модуль».
   Распакуйте архив в корень WHMCS: файлы лягут в `modules/servers/vortanix`.
2. Там же нажмите «Выпустить ключ для WHMCS» и скопируйте ключ. Ключ получает
   только право `admin.whmcs.write` и не открывает остальную админку.
3. В WHMCS откройте System Settings → Servers → Add New Server:
   - Module — Vortanix;
   - Hostname — домен панели, например `panel.example.com`;
   - Access Hash — ключ из шага 2;
   - Secure — включено.

   Нажмите Test Connection.
4. Создайте группу серверов и добавьте в неё сервер.
5. Создайте продукт. На вкладке Module Settings выберите модуль Vortanix,
   группу серверов из шага 4 и тариф панели. Укажите, когда создавать
   сервер, например после оплаты первого счёта.
6. В панели укажите адрес WHMCS: по нему строятся ссылки на услугу клиента.

Вход клиентов из WHMCS формирует ссылку на адрес панели из переменной
окружения `FRONTEND_URL`.

## Настройки продукта

| Поле | Значение |
|---|---|
| Тариф панели | Обязательное. Определяет ресурсы и игру |
| Игра | Пусто — игра тарифа |
| Локация | «Автоматически» — наименее загруженная локация, где хватает места для игры |
| Версия игры | ID или название версии. Пусто — версия по умолчанию |
| Слоты, ядра CPU, ОЗУ, диск | 0 — значение из тарифа |
| Название сервера | Шаблон с подстановками `{service_id}`, `{client_id}`, `{domain}`. Пусто — название игры и номер услуги |

## Выбор клиента при заказе

Чтобы клиент выбирал параметры сам, создайте настраиваемые опции
(Configurable Options) с именами из таблицы. Отображаемое название задаётся
через черту: `cs16|Counter-Strike 1.6`.

| Имя опции | Значение |
|---|---|
| `game` | Код игры из каталога панели, например `cs16` |
| `location` | ID, код или название локации |
| `version` | ID или название версии игры |
| `slots`, `cpu_cores`, `ram_gb`, `disk_gb` | Число |
| `tariff` | ID тарифа панели |

Название сервера клиент указывает в поле клиента (Custom Field) с именем
`server_name`. Значения опций и полей важнее настроек продукта.

## Заказ только через WHMCS

Флажок «Принимать заказы серверов только в WHMCS» отправляет клиентов со
страницы аренды панели в WHMCS и запрещает аренду серверов с баланса панели.
Пробный сервер на странице аренды в этом режиме не предлагается. Веб-хостинг
и пополнение баланса продолжают работать.

## Учётные записи

- Клиент WHMCS связывается с учётной записью панели по номеру клиента. При
  первом заказе учётная запись ищется по email, а если её нет, создаётся с
  паролем услуги из WHMCS.
- Email сотрудника панели нельзя использовать для клиента WHMCS: создание
  услуги завершится ошибкой, вход сотрудником из WHMCS запрещён.
- Если учётная запись уже была, её пароль не меняется. Клиент входит кнопкой
  из WHMCS или прежним паролем.

## API

Модуль обращается к `https://<панель>/v1/admin/whmcs` с заголовком
`X-API-Key`. Этими методами можно пользоваться из собственных скриптов.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/info` | Проверка подключения |
| GET | `/catalog` | Игры, тарифы, локации и версии игр |
| GET | `/services` | Список услуг |
| GET | `/usage` | Занятое место на диске по услугам |
| POST | `/services/{id}` | Создать сервер; повторный вызов возвращает уже созданный |
| GET | `/services/{id}` | Данные услуги и сервера |
| DELETE | `/services/{id}` | Удалить сервер |
| POST | `/services/{id}/suspend` | Приостановить |
| POST | `/services/{id}/unsuspend` | Возобновить |
| POST | `/services/{id}/package` | Сменить тариф и ресурсы |
| POST | `/services/{id}/renew` | Обновить дату следующего платежа |
| POST | `/services/{id}/password` | Сменить пароль учётной записи |
| POST | `/services/{id}/power` | `start`, `stop`, `restart` или `kill` |
| POST | `/services/{id}/reinstall` | Переустановить сервер |
| POST | `/services/{id}/sso` | Одноразовая ссылка для входа, действует 2 минуты |
| PUT | `/clients/{id}` | Обновить email и имя клиента |

`{id}` — номер услуги или клиента в WHMCS.

## Диагностика

- Запросы модуля и ответы панели пишутся в журнал WHMCS System Logs → Module
  Log, если журнал включён.
- `invalid api key` — ключ отозван или скопирован не полностью.
- `ключ не имеет права admin.whmcs.write` — выпустите ключ кнопкой в разделе
  WHMCS.
- `не задан публичный адрес панели (FRONTEND_URL)` — задайте переменную
  окружения, иначе вход из WHMCS не сформирует ссылку.
